CONEXIÓN LOCAL

Vincula tu asistente

La extensión se conecta únicamente con el backend de tu equipo. El código temporal se usa una vez y el token no se entrega al chat de Stripchat.

Comprobando el backend local…
Solo se permiten direcciones HTTP de 127.0.0.1 autorizadas por el manifiesto.
El campo se vacía al iniciar el intento. El código no se guarda en preferencias.

¿Dónde obtengo el código?
  1. Inicia el backend local.
  2. En una consola abierta en la carpeta del proyecto, ejecuta python -m backend.auth_admin pair.
  3. Pega aquí el código antes de que pasen cinco minutos.

Si ya habías vinculado esta extensión y perdiste su token, usa python -m backend.auth_admin rotate. El comando solicita confirmación y revoca el token anterior.

No pegues el código en Stripchat, DevTools, una URL ni una conversación.

Las sugerencias siguen bajo tu revisión y envío manual.
